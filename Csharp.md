# C#

## INTRODUCTION

### ¿Qué es C#?

Pronunciación: C-Sharp.

Paradigma y creador: Lenguaje orientado a objetos creado por Microsoft que se ejecuta sobre el .NET Framework.

Familia e influencias: Pertenece a la familia de C y guarda cercanía con lenguajes populares como C++ y Java.

Historial de versiones: Primera versión lanzada en 2002; la versión C# 14 se publicó en noviembre de 2025.

### ¿Para qué se utiliza?

Aplicaciones móviles y de escritorio

Aplicaciones web, servicios web y sitios web

Juegos y realidad virtual (VR)

Aplicaciones de bases de datos y mucho más

### ¿Por qué usar C#?

Popularidad y Comunidad
Es uno de los lenguajes más populares y cuenta con un gran soporte comunitario.

Curva de aprendizaje
Es sencillo de usar y fácil de aprender, sin requerir experiencia previa para empezar.

Estructura y Reutilización
Su enfoque orientado a objetos aporta estructura clara, reutiliza código y reduce costos de desarrollo.

Transicion ágil
Su similitud con C, C++ y Java facilita cambiar entre estos lenguajes.
